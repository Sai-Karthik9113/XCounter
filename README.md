# Counter App

This is a simple React app that allows users to increment and decrement a counter value. It demonstrates the use of React's `useState` hook for managing state in a functional component.

## Features
- **Increment/Decrement**: Users can increase or decrease the counter value by clicking the respective buttons.
- **Real-time Updates**: The count is displayed in real-time as the buttons are pressed.

## Technologies Used
- **React**: The core library used for building the user interface and handling state.
- **JavaScript**: Manages the counter logic.
- **CSS**: Basic styling for layout (optional, depending on your `App.css` file).

## How to Run the Project Locally

1. Clone the repository:
   ```
   git clone https://github.com/Sai-Karthik9113/XCounter.git
   ```
2. Navigate to the project directory:
   ```
   cd counter-app
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```

5. Open the app in your browser at `http://localhost:3000`.
